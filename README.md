# しばサバイバー

柴犬が押し寄せる犬の群れを自動攻撃でなぎ倒す、縦画面スマホ向けのサバイバーゲーム。5分生きのびて、最後に出てくるセントバーナードを倒せばクリア。

**https://yasufabric.github.io/shiba-survivor/**

スマホのブラウザで「ホーム画面に追加」すると、全画面のアプリとして開き、オフラインでも遊べる。

## 遊び方

- 指でなぞると柴が動く。攻撃は自動。
- 倒した犬が落とすホネを拾ってレベルアップ。3つの中から技か強化を1つ選ぶ。
- 技がLv5になって、対応する強化を持っていると進化できる。

| 技 | 進化に必要な強化 | 進化後 |
| --- | --- | --- |
| ホネ投げ | きんトレ | ホネ乱れ投げ |
| しっぽボール | はやあし | しっぽ大回転 |
| ワン! | もふもふ | 遠吠え |
| おなら | おやつ | 最終おなら |
| 肉球スタンプ | はやぐい | 肉球メテオ |
| フリスビー | はなが利く | フリスビー乱舞 |
| リードぶんぶん | くびわ | リード大旋風 |

## 柴の毛色

| 柴 | はじめの技 | とくちょう | 仲間になる条件 |
| --- | --- | --- | --- |
| 赤柴 | ホネ投げ | — | 最初から |
| 黒柴 | ワン!（Lv2） | 威力 +15% | 3分生きのびる |
| 白柴 | しっぽボール | HPが自然回復 | 合計1000匹たおす |
| 胡麻柴 | フリスビー（Lv2） | 足が速い | ボスをたおす |

## はげしい散歩

一度ボスをたおすと、タイトルで「はげしい」を選べる。犬が1.6倍かたく、1.3倍いたく、湧きが1.25倍速く、ボスのHPが1.5倍。ボスをたおした後は「まだ散歩する」でエンドレスに進める。

## きょうの散歩

日替わりのルールで遊ぶモード。ルールは日本時間の日付で決まり、その日のベスト記録が残る。

| ルール | 内容 |
| --- | --- |
| チワワまつり | 出てくるのはチワワだけ。そのかわり3倍かたい |
| ホネ2倍デー | ホネの経験値が2倍。犬は1.4倍かたい |
| はやあし世界 | 犬が1.3倍速い。柴も1.2倍速い |
| ガラスの柴 | 最大HPが半分。攻撃は1.6倍 |
| 進化びより | 引き直し5回、宝箱が25秒ごと |

## つくり

`index.html` 1枚だけ。ビルドなし、外部ライブラリなし。Canvas 2D のドット絵（コードで生成）と Web Audio の合成音。フォントは Google Fonts の DotGothic16。

`main` に push すると GitHub Actions が Pages に公開する。
